# Archive

Documents kept for the history they record, not for the tree they describe.

Each one opens with a banner naming what in it is stale. They were written
against the pre-Phase-3 code and name routes, columns, crates and file layouts
that no longer exist. `docs/spec-dnsnet-plus-four.md` is the contract now:
sections 1 and 2 for the crates and the schema, section 3 for the HTTP API,
sections 4 and 6 for the pages and the per-device model.

They live here rather than in `docs/architecture/` so that opening that
directory gets you a current map and nothing else.
